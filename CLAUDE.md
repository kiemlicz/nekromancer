# Critical rules

- **Never commit unencrypted secrets.** Encrypt secrets first.
- Prove that each change is valid by testing it
- When deciding to add comment - be terse

## Markdown Formatting & Line Wrapping

- **Target Line Length:** Write fuller, longer lines aiming for up to ~140 characters before wrapping. Avoid premature line breaks around 80 characters. This 140-character target is a soft guideline, not a strict hard limit.
- **Semantic Line Breaks:** When wrapping prose, place newlines after punctuation marks (`.`, `,`, `;`, `:`, `—`) or natural clause boundaries rather than breaking mid-phrase.
- **Unbroken Elements:** Allow lines containing long URLs, inline code, file paths, or markdown tables to exceed 140 characters rather than breaking their syntax.
